# 产品说明

CourseDrop，中文名“课递”，是一个本地优先的加密文件投递、临时中转与可视化分享管理工具。

它不是网盘，也不是完整聊天软件。项目重点是用手机端管理本地内容，通过公网限时中转、浏览器下载、扫码登录、端到端加密和过期清理完成跨设备投递。群组功能用于 Telegram 式群组文件投递，但第一版不做完整 IM 体验。

## 核心定位

```text
本地优先文件投递工具 = 本地库 + 公网限时中转 + 浏览器/App 下载 + 端到端加密 + 群组文件流
```

## 不做什么

- 不做永久网盘。
- 不做普通文件目录同步。
- 不做朋友圈、动态、评论区。
- 不做完整聊天系统。
- 不把服务器变成可读取明文的文件仓库。

## 典型场景

### 临时分享

- 用户在手机 CourseDrop 中选择本地文件。
- 客户端按需要加密文件。
- 手机上传密文/文件到公网中转服务器。
- 服务端生成分享码、浏览器下载 URL 和二维码。
- 接收方可以用 CourseDrop App 下载，也可以在浏览器中下载。
- 服务器只在有效期内保存内容，到期或撤回后删除。

### 群组文件流

- 用户创建加密群组。
- 成员通过邀请链接或后续扫码加入。
- 发送端上传群组密文文件。
- 发送端发送 `FILE` 密文消息，payload 内包含文件名和 file key。
- 成员同步密文消息后下载密文文件，并在本地解密。
- 服务端不保存群组 key、file key、明文群名、明文消息或明文文件。

## 项目亮点

- 鸿蒙原生 ArkTS / ArkUI 客户端。
- Java Spring Boot 轻量后端。
- 设备指纹为默认身份，账号是可选增强。
- 手机扫码登录 Web 下载页。
- 浏览器下载降低接收方安装门槛。
- 服务器限时存储，避免变成普通网盘。
- 端到端加密，服务器只处理中转密文。
- 群组文件流支持多人文件投递，但暂不扩展完整聊天能力。
