# 产品路线

## 当前定位

CourseDrop / 课递不是普通文件传输工具，也不是系统文件管理器。

它的定位是：

```text
本地优先的加密文件投递与分享管理工具
```

和系统自带文件传输的差异：

- 系统传输偏“附近设备之间发送文件”。
- CourseDrop 偏“围绕一次文件投递的生命周期管理”。
- 系统传输通常要求同生态、同网络或近场能力。
- CourseDrop 要支持浏览器下载、扫码登录、公网限时中转、端到端加密、群组文件流和过期清理。

一句话目标：

```text
让用户把文件安全、临时、可追踪地投递给另一台设备、浏览器或群组，而不把服务器变成网盘。
```

## 第 1 阶段：公网限时投递闭环

状态：已基本具备。

范围：

- 配置中转源。
- 注册本机指纹身份。
- 本地库生成或导入真实文件。
- 文件加入分享草稿。
- 创建公网分享链接。
- 上传文件或密文到中转服务器。
- 浏览器/App 打开分享链接并下载。
- 过期、撤回或删除单项后服务器清理。

## 第 2 阶段：扫码与身份体验

状态：已具备基础能力，真实扫码解码仍待补。

范围：

- 分享二维码展示。
- 浏览器网页登录二维码。
- 手机 App 确认登录。
- App 分享码下载。
- 无账号默认使用手机指纹身份。
- 可选创建账号并绑定多个手机指纹。

## 第 3 阶段：端到端加密

状态：客户端和服务端已有第一版。

范围：

- 客户端上传前加密。
- 服务端保存密文和加密元数据。
- 浏览器端 WebCrypto 解密基础能力。
- App 端下载后解密。
- 错误 key、过期、篡改都能明确失败。

后续重点：

- 升级 key fragment 为版本化 JSON + Base64URL。
- 多文件 key map。
- 完整性校验 UI。

## 第 4 阶段：App 内下载与本地库管理

状态：已具备基础能力。

范围：

- App 输入分享码或扫码进入下载详情。
- App 身份鉴权下载。
- 下载到 CourseDrop 应用目录。
- 写入本地库索引。
- 本地库按来源、分享会话、状态和过期时间管理内容。

## 第 5 阶段：群组文件流

状态：Java server MVP、服务端 WebSocket 实时通知基础、账号级密文群 key 备份、鸿蒙端群组 UI 与本地持久化已具备第一版。

目标：

```text
创建群 -> 加入成员 -> 上传群组密文文件 -> 发送 FILE 密文消息 -> 成员同步消息 -> 下载解密
```

当前已具备：

- 服务端群组、成员、密文消息、密文文件。
- 服务端群组文件上传下载和权限校验。
- 服务端 `/api/groups/mine` 可按设备身份列出已加入群组。
- 服务端 `/api/groups/{groupId}/members` 可供群成员查看成员列表。
- 服务端 `/ws/groups` 可向在线成员广播群组密文消息事件。
- 服务端 `/api/groups/{groupId}/key-backups/me` 和 `/api/groups/key-backups/mine` 可保存和列出账号级密文群 key 备份。
- 鸿蒙端群组模型、AES-GCM 加密、HTTP contract、WebSocket 实时事件订阅与退避重连、密钥备份 service、成员同步、群资料面板、群组列表/会话 UI、本地 Preferences 持久化。

下一步：

- 完善前后台生命周期，后台时降低实时连接活跃度，回到前台后补拉 cursor。
- 将群组入口接入主流程，但不放到设置页，入口由产品侧单独决定。
- 将恢复口令 KDF 从 SHA256-PASSPHRASE-V1 升级到更强的 PBKDF2/Argon2 参数化方案。
- 补远端群资料更新、成员移除、管理员角色等完整群管理能力。

设计原则：

- 群组也基于用户配置的源服务器，不绑定官方公网服务。
- 源服务器只保存密文和成员关系，不保存明文或可恢复密钥的材料。
- 一对一会话先放入规划，不进入当前阶段实现。

## 第 6 阶段：局域网优先直传

状态：发现层已有服务边界，直传未完成。

范围：

- 局域网设备发现。
- 同网络设备直连传输。
- 直传失败后切换公网中转。
- 设备页展示真实设备和连接状态。

## 第 7 阶段：诊断、稳定性和演示打磨

范围：

- 诊断页展示当前中转源、身份、最近请求、最近错误、本地库根目录。
- 上传/下载失败重试。
- 分享撤回、续期、删除审计展示。
- 模拟器扫码测试说明。
- GitHub Actions 自动部署服务器。

## 暂缓

- 完整聊天系统。
- 群组复杂管理。
- 一对一加密会话。
- 长期文件仓库。
