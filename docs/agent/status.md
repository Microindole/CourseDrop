## Java 服务端

- 技术栈：Java 17、Spring Boot 3、SQLite、MyBatis-Plus、Thymeleaf、Tailwind CDN。
- 旧版房间/传输项接口仍保留为兼容层。
- 公网分享主链路已完成：
  - 创建分享、上传分享项、查询下载页信息。
  - 浏览器下载页 `/s/{code}`。
  - App 下载接口。
  - 分享撤回、续期、删除单项、我的分享和状态筛选。
  - 分享删除审计。
- 身份与账号已完成：
  - 设备指纹注册。
  - 账号创建、账号登录绑定当前指纹。
  - 账号密码登录开关、修改密码、设备绑定/解绑。
  - Web 扫码登录、Cookie 签发、退出、撤销和会话列表。
- E2EE 服务端边界已完成：
  - 上传时校验加密元数据。
  - 服务端保存密文和元数据，不保存 file key。
  - 浏览器下载页具备 `#key=` WebCrypto 本地解密基础能力。
- 群组文件流 MVP 已完成：
  - 创建群、获取群、加入群、退出群。
  - 发送密文消息、按 cursor 同步消息。
  - 上传群组密文文件、成员下载密文文件。
  - 非成员访问拒绝。
  - 群组文件过期清理接入 `CleanupService`。
- 数据库初始化收敛为带版本表的轻量迁移服务。
- 清理任务会保护旧版 transfer、share、group 三类 storage key。
- 服务端测试覆盖健康检查、分享主流程、扫码 Cookie、账号安全、加密元数据、分享管理和群组文件流。

## 鸿蒙客户端

- 主入口为 `HomePage`，底部 Tab 承载首页、分享、本地库、设备和设置。
- 本地库已支持应用目录、RDB 索引、导入、生成测试文件、搜索、类型筛选、分页、详情抽屉、批量加入分享草稿和删除索引。
- 分享页已围绕分享草稿、公网链接、上传任务、二维码、撤回、续期和失败重试组织。
- 接收分享页支持分享码读取、App 身份鉴权下载、写入 `incoming/` 并建立本地库索引。
- 设置页支持中转源配置、健康探测、本机身份、账号创建和账号密码登录开关。
- 客户端 E2EE 已替换占位实现：
  - 上传前 AES-256-GCM 加密。
  - 密钥放入分享链接 fragment。
  - 接收页解析 `#cdkey=` 后下载密文并本地解密入库。
- 扫码服务已有边界，当前真实二维码解码仍待接 Scan Kit 或图像解码库。
- 局域网发现已使用 UDP 广播服务边界，直传协议未完成。
- 群组模块已进入独立测试阶段：
  - 群组模型和本地仓储。
  - 群组 AES-GCM 加密。
  - 群组 HTTP contract 对接 Java server。
  - `GroupTestPage` 可用于独立验证注册身份、创建群、发送密文文本消息、同步并本地解密。
