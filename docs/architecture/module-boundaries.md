# 模块边界

这份文档说明各模块负责什么，以及不应该负责什么。

## Monorepo 边界

```text
apps/harmony/          鸿蒙客户端
apps/server/           Java 服务端
packages/api-contract/ API 契约
docs/                  文档
deploy/                部署配置
scripts/               本地辅助脚本
.github/               CI 工作流和复用 action
```

## 服务端边界

### common

职责：

- 通用异常
- 通用错误响应

不放：

- 业务流程
- 数据库访问

### config

职责：

- Spring 配置
- 配置属性
- 数据库迁移和初始化

不放：

- Controller
- 业务流程

### controller

职责：

- HTTP 参数接收
- 调用 service
- 组装响应

不放：

- 业务校验细节
- 文件存储细节
- 数据库访问

### dto / enums / entity / mapper

职责：

- `dto`：Request、Response、页面响应对象。
- `enums`：业务枚举。
- `entity`：数据库表实体。
- `mapper`：MyBatis-Plus mapper 和仓储转换。

不放：

- 页面逻辑
- 网络外部调用
- 文件加密或解密逻辑

### share

职责：

- 公网分享会话。
- 分享码和浏览器下载 URL。
- 分享过期、撤回、续期和删除单项。
- 分享项元数据。
- App 下载和浏览器下载的业务校验。

不放：

- 实际文件落盘。
- 账号密码校验细节。
- 设备指纹绑定细节。
- 群组成员关系。

### group

职责：

- 加密群组文件流。
- 群组元数据内部记录。
- 群组成员关系。
- 群组密文消息。
- 群组密文文件记录。

不放：

- 完整 IM 聊天体验。
- 明文群名、明文消息、群组密钥。
- 浏览器下载页面。
- 局域网直传协议。

### identity

职责：

- 设备指纹注册。
- 账号创建。
- 登录已有账号并绑定当前指纹。
- 账号与多个设备指纹绑定。
- 将已绑定设备指纹解析为账号身份。

不放：

- 分享文件存储。
- 群组消息存储。
- 下载流输出。

### auth

职责：

- 手机扫码登录 Web 管理端。
- Web 登录会话。
- 账号密码登录例外入口。

不放：

- 分享业务。
- 群组业务。
- 文件清理。

### storage

职责：

- 临时文件保存。
- 文件路径解析。
- 文件删除。
- 文件列表。

不放：

- 下载授权判断。
- 分享或群组业务判断。
- 解密密钥处理。

### cleanup

职责：

- 定时清理过期分享、群组文件和旧版传输项。
- 删除过期文件。
- 扫描并删除孤儿文件。

不放：

- 手动删除接口。
- 业务查询接口。

### room / transfer

职责：

- 早期房间和传输项兼容接口。

不放：

- 新公网分享能力。
- 群组文件流能力。

## 客户端边界

### common

职责：

- App 配置。
- 主题颜色。
- Preferences。
- RDB Store。
- 运行时上下文。

### models

职责：

- 与 API 对齐的数据类型。
- 页面之间传递的轻量结构。

不放：

- 网络请求。
- UI 逻辑。
- 文件读写。

### services

职责：

- REST 请求。
- 文件选择、复制、上传、下载。
- CourseDrop 应用专属文件库索引。
- 中转源配置。
- 设备发现。
- 剪贴板。
- 加密和解密。
- 群组加密、群组网络契约和本地群组仓储。

不放：

- 页面布局。
- 长段 UI 状态。

说明：

- 页面数据必须通过 services 进入 viewmodels。
- services 按领域拆成接口、仓储和实现。
- 后续替换真实文件 API、SQLite、HTTP、局域网发现时，优先替换 service 实现，不改页面结构。

### viewmodels

职责：

- 页面状态。
- 表单校验。
- 调用 service 后整理成页面可展示状态。

### pages

职责：

- 页面结构。
- 页面级事件绑定。
- 导航。
- 独立测试页。

不放：

- 复杂网络细节。
- 文件存储细节。
- 加密实现。

### components

职责：

- 可复用 UI 组件。
- 不绑定具体业务数据源。
- 统一使用 `Cd` 前缀。
- 组件样式从 `common/Theme.ets` 读取。

不放：

- 页面级业务流程。
- 网络请求。
- 临时随手写的单页样式。

## API 契约边界

`packages/api-contract` 用于放 OpenAPI、事件 schema 等跨端契约。

当客户端和服务端字段不一致时，优先更新契约，再同步两端实现。
