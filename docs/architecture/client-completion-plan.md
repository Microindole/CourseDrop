# 鸿蒙客户端补全计划

## 产品边界

CourseDrop 客户端不做另一个系统文件传输工具，也不做完整聊天应用。

它要解决的是：

```text
本地优先、端到端加密、支持公网限时中转和群组文件流的跨设备文件投递与分享管理
```

客户端的核心体验不是“选文件发送”，而是管理文件投递生命周期：

```text
本地入库 -> 选择分享内容 -> 加密/打包 -> 创建分享或群组文件 -> 上传 -> 扫码/登录/同步下载 -> 解密入库 -> 过期清理
```

## 当前已具备

- 首页、分享、本地库、设备、设置的底部 Tab 主结构。
- 设置页可配置多个公网中转源，并可探测健康状态。
- 本机身份可注册到中转服务器，身份信息已持久化。
- 本地库已接入应用专属目录和 RDB/SQLite 索引基础设施。
- 本地库可生成测试文件、导入系统文件/图片、搜索、类型筛选、分页、详情查看、批量选择、加入分享草稿和删除索引。
- 分享页已围绕 CourseDrop 分享草稿、公网链接、二维码和上传任务组织。
- 分享草稿可从本地库加入，也可通过系统文件选择器加入。
- 公网分享创建已接入服务端 `/api/shares`。
- multipart 上传已进入主链路。
- App 下载服务已接 `/api/shares/{code}/items/{itemId}/download`。
- App 下载成功后写入 `incoming/`，并保存到本地库索引。
- 分享页可调用服务端二维码接口展示真实下载二维码。
- 分享链接复制已接系统剪贴板。
- 客户端 E2EE 已用 `cryptoFramework` 替换占位加密。
- 接收分享页可解析 `#cdkey=`，下载密文后本地解密。
- 扫码内容解析已有服务边界，可解析网页登录和分享链接。
- 局域网发现已改为 UDP 广播服务边界。
- 群组模型、群组 AES-GCM 加密、群组 HTTP contract 和 `GroupTestPage` 已建立。

## 当前重点：群组独立测试

当前不要先接主流程。先用 `GroupTestPage` 独立验证：

```text
设置中转源 -> 注册本机身份 -> 创建测试群 -> 发送密文文本消息 -> 同步并本地解密显示
```

验收：

- 群组创建成功。
- 服务端数据库看不到群名和消息明文。
- 同步后客户端能本地解密显示消息。
- 页面仍不出现在首页 Tab 或普通分享流程中。

## 下一步：群组文件投递

目标：

```text
选择文件 -> 加密文件 -> 上传群组密文文件 -> 发送 FILE 密文消息 -> 同步消息 -> 下载密文 -> 本地解密入库
```

需要完成：

- 在 `GroupTestPage` 中接系统文件选择器。
- 复用或封装 `EncryptionService` 完成文件 AES-GCM 加密。
- 调用 `GroupNetworkContract.uploadFile` 上传密文文件。
- 构造 `PlainFilePayload`，用 `GroupCryptoService.encryptFilePayload` 加密为 `GroupMessage`。
- 调用 `GroupMessageService.sendFileMessage`。
- 同步 `FILE` 消息后调用 `GroupNetworkContract.downloadFile`。
- 用 payload 中的 file key 本地解密。
- 写入 `incoming/` 或本地库索引。

验收：

- 群组成员能下载并解密文件。
- 非成员无法下载。
- 服务端只保存密文文件和元数据。
- 文件名、file key 等用户可读信息只存在于群组密文 payload。

## 仍需补齐

### 二维码和扫码

- 当前系统相机只能返回拍摄 URI。
- 后续接 Scan Kit 或图像解码库，完成二维码文本识别。
- 扫码入口统一由 `ScanDispatchService` 分发。

### 账号安全

- 已支持创建账号并绑定当前指纹。
- 已支持开启或关闭账号密码登录。
- 仍需补已绑定设备列表、解绑设备和修改密码 UI。

### 局域网直传

- 当前只完成 UDP 广播发现。
- 仍需 TCP/UDP 文件直传服务、监听端、握手协议、进度和失败回退。

### E2EE 格式升级

- 分享 `#cdkey=` fragment 当前是第一版文本格式。
- 后续应升级为版本化 JSON + Base64URL，并支持多文件 key map 和完整性校验 UI。

## 推荐实施顺序

1. 群组独立测试页联调通过。
2. 群组文件投递闭环。
3. 群组入口设计和主流程接入。
4. 二维码真实解码。
5. 账号设备管理。
6. 局域网直传。

## 暂缓

- WebSocket 实时推送。
- 消息已读、撤回、编辑。
- 群主踢人、解散群和密钥轮换。
